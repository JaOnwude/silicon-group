# JavaScript Coding Test

This repo contains a set of beginner-to-intermediate JavaScript coding challenges.

## Tests

- `absolute-difference`
- `simple-array-sum`
- `unique-array-sum`
- `compare-triplets`
- `birthday-cake-candles`
- `strong-password`
- `function-dispatch`
- `time-conversion`

## How to run a test

Each folder has its own `solution.js` and `test.js`. To test your solution:

With Bun:

```bash
bun run test.js
```

With Node.js:

```bash
node test.js
```

Run these commands from inside the folder for the challenge you are working on.

## Submission instructions

1. Solve each challenge in its `solution.js` file.
2. Make sure all tests pass by running `bun run test.js` or `node test.js`.
3. Create a **private** repository on GitHub and push your code there.
4. Add `theodoremca` as a collaborator to your repository.
5. Submit the repository link.

## Time limit

You have **75–90 minutes** to complete the required tests.
