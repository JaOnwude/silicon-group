# Absolute Difference

## Problem

Given two integers `a` and `b`, return the absolute difference between them.

The absolute difference is the positive distance between the two numbers on the number line.

## Example

```
a = 3
b = 5
```

Return:

```
2
```

```
a = -3
b = 5
```

Return:

```
8
```

## Function Description

Complete the `absoluteDifference` function in `solution.js`.

- `int a`: the first value
- `int b`: the second value

Returns:
- `int`: the absolute difference between `a` and `b`

## Constraints

- `-1000 <= a, b <= 1000`

## Sample Input / Output

```
Input:  a = 5, b = 3
Output: 2
```

```
Input:  a = -3, b = 5
Output: 8
```

```
Input:  a = 10, b = 10
Output: 0
```
