# Simple Array Sum

## Problem

Given an array of integers, find the sum of its elements.

For example, if the array `ar = [1, 2, 3]`, then `1 + 2 + 3 = 6`, so return `6`.

## Function Description

Complete the `simpleArraySum` function in `solution.js`.

- `int[] ar`: an array of integers

Returns:
- `int`: the sum of the array elements

## Constraints

- `0 < n, ar[i] <= 1000` where `n` is the length of the array

## Example

```
ar = [1, 2, 3]
```

Return:

```
6
```

## Sample Input / Output

```
Input:  [1, 2, 3, 4, 10, 11]
Output: 31
```

Explanation: `1 + 2 + 3 + 4 + 10 + 11 = 31`.
